# Shriya Group — Upcoming

Minimal static landing page. No framework, dependencies, or build step required.

## Deploy to Vercel
1. Upload this folder to a GitHub repository.
2. In Vercel, select **Add New → Project** and import the repository.
3. Keep **Framework Preset: Other**. Leave Build Command empty and Output Directory as `.` (or the default static output setting).
4. Deploy.
5. In **Project → Settings → Domains**, add `shriyagroup.co` (and optionally `www.shriyagroup.co`).
6. Apply the exact DNS records Vercel displays at the domain registrar. Vercel will verify the domain and provision HTTPS.

The domain is not connected automatically by this source folder; it must be attached to the Vercel project and configured at the registrar.
